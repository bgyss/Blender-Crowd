# M6 reference fixtures

These small, redistributable JSON fixtures exercise M6 schema and contract
validation. They are not licensed motion data, neural checkpoints, or proof of
production-scale motion quality. The paired interaction fixture is an authored
deterministic baseline for the R0 request/response path.

The fixture set also includes activity, formation, terrain/foot-lock,
paired-interaction, recovery, retarget, and mixed-tier scene contracts. These
are acceptance inputs and schema/ordering fixtures; they are not production
motion-quality or independent-user evidence.
