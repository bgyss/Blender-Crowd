# Blender Crowd 1.0 support matrix

Status: release contract. Blender Crowd 1.0 claims exactly one platform:
Blender 5.2 LTS on macOS Apple Silicon. That platform is not accepted until its
archive and locally executable M3 gates pass in the dated acceptance report.

| Host | OS / architecture | Extension archive | Status | Evidence required |
| --- | --- | --- | --- | --- |
| Blender 5.2 LTS | macOS 11+ / Apple Silicon | `blender_crowd-1.0.0.zip` | candidate | `scripts/m3-acceptance.sh` plus the M3 release-policy review |

Windows, Linux, Intel macOS, and macOS versions before 11 are outside the 1.0
support contract. They are future portability targets, not unverified 1.0
claims. Blender versions before 5.2 and architectures not named above are also
unsupported. The abi3 wheel is a CPython ABI statement, not evidence that an
arbitrary Blender version, operating system, or CPU is supported.
