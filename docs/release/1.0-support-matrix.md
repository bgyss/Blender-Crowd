# Blender Crowd 1.0 support matrix

Status: release contract; no platform is accepted until an archive pass and
independent evaluator record are attached to the dated acceptance report.

| Host | OS / architecture | Extension archive | Status | Evidence required |
| --- | --- | --- | --- | --- |
| Blender 5.2 LTS | macOS 11+ / Apple Silicon | `blender_crowd-1.0.0-macos-arm64.zip` | candidate | `scripts/m3-acceptance.sh` plus two evaluator records |
| Blender 5.2 LTS | Windows 11 / x86_64 | `blender_crowd-1.0.0-windows-x64.zip` | not yet built | same archive gate |
| Blender 5.2 LTS | Ubuntu 22.04+ / x86_64 | `blender_crowd-1.0.0-linux-x64.zip` | not yet built | same archive gate |

Blender versions before 5.2 and architectures not named above are unsupported.
The abi3 wheel is a CPython ABI statement, not evidence that an arbitrary
Blender version, operating system, or CPU is supported.
