# Blender Crowd 1.0 release-policy review

## Dependency and license decision

The deterministic SPDX 2.3 inventory generated from the locked Cargo graph was
reviewed on 2026-08-12. It contains 142 packages, no missing license assertions,
and only the project's GPL-3.0-or-later license plus permissive, Unicode, or
LGPL alternative expressions suitable for distribution with this GPL work.
The decision is pinned to both `Cargo.lock` and the generated SBOM hashes in
[`1.0-release-review.json`](1.0-release-review.json); changing either invalidates
the review and stops the archive audit.

## Signing applicability

The 1.0 channel is a Blender extension ZIP installed directly or served from a
static Blender extension repository. Blender's official extension CLI documents
build, validate, install-file, and repository generation, but no package-signing
step for this channel. Therefore Apple application signing/notarization is not
applicable to this extension ZIP. The release integrity controls are the
reproducible archive, `SHA256SUMS`, archive audit, exact native platform tag,
SBOM, and source provenance. A future channel that defines signing must reopen
this decision. See the [Blender extension CLI documentation](https://docs.blender.org/manual/en/latest/advanced/command_line/extension_arguments.html).

## Documentation review

The user, behavior/node, authoring, schema/cache, compatibility, recovery,
headless, support, limitation, and budget documents listed in the
machine-readable review are staged into the archive. The archive-first runner
exercises their commands and policies through clean install, bake, cache-only
render, invalid-cache recovery, and release audits.
