# Blender Crowd 1.0 macOS arm64 budgets

These thresholds are fixed before the next 1.0 candidate is built. They turn
the canonical contract's checked M2/M3 calibration measurements into an
enforcing macOS arm64 release gate; a later candidate may not loosen them after
its result is known.

The workload is the complete 1,000-agent, 10,000-tick reference shot at the
checked 320 x 180 render resolution. The limits preserve substantial variance
headroom over the 2026-08-12 calibration while still rejecting unbounded
resource growth: 120 seconds bake time, 6 GiB peak Blender RSS, 1.25 GiB cache,
2 MiB archive, 50 ms point upload, 100 ms for 31 armature frames, and 5 seconds
per reference render. Sequential native cache playback must sustain 100 ticks/s
and a cached-agent debug query must complete within 100 ms on average.

Quality is enforced separately by the six exact checked solver baselines, the
strict deterministic rebake, release-density suite, and two-room reroute gate.
The machine-readable thresholds live in
[`1.0-budgets.json`](1.0-budgets.json) and are applied by
`scripts/m3_budget_audit.py`; measurements never count as passes without that
report.
