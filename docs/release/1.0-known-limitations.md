# Blender Crowd 1.0 candidate limitations

This candidate has not passed the M3 release gate. Blender Crowd 1.0 supports
only Blender 5.2 LTS on macOS 11+ Apple Silicon; Windows, Linux, Intel macOS,
and other Blender versions are unsupported. Do not represent this checkout,
its wheel, or a manually assembled zip as a released Blender Crowd 1.0 archive.

Blender's Metal startup crashes under the restricted Codex filesystem sandbox.
Release validation and acceptance must run with normal host Metal access. This
is an execution-environment limitation, not a supported product configuration.

The product scope remains the documented 1,000-agent transit-concourse
workflow. It does not claim USD layering, 10K/100K scale, advanced motion
matching, physics handoff, or Blender mainline readiness.

For cache recovery, inspect the cache health before attachment and rebake any
canceled, incomplete, corrupt, or stale cache. The safe support bundle omits
scene contents, absolute paths, and full diagnostic details by design.
